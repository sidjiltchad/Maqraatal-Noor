# Maqraatal-Noor — مشروع الأندرويد

تطبيق «مقرأة النور» (Maqraatal-Noor) — حلقات قرآنية للنساء: عربي وحده،
RTL، بلا خادم في هذه النسخة. التصميم المنفَّذ هو تصميم النسخة الأولى
v1.1 الموجود في جذر هذا المستودع (`DESIGN-SPEC.md` + صور الشاشات).

## التسمية

- الاسم اللاتيني للمشروع في الملفات كلها: **Maqraatal-Noor** (كما في
  اسم المستودع)، و`rootProject.name = "Maqraatal-Noor"`.
- معرّف التطبيق: `org.maqraatalnoor` (بلا شرطة، لأن الشرطة ممنوعة في
  معرّف الحزمة)، ومسار الحزمة: `org/maqraatalnoor`.
- اسم العرض في الواجهة عربي: «مقرأة النور».

## البناء

إصدارات الأدوات منسوخة من مشروع Majlis Studio العامل على جهاز يعقوب
(لا إصدارات جديدة مخترعة): Gradle 8.10.2، AGP 8.7.3، Kotlin 2.0.21،
compileSdk/targetSdk 35، minSdk 29، Java 17.

```powershell
cd android
.\gradlew.bat :app:assembleDebug
```

أو على Linux/macOS:

```bash
cd android
./gradlew :app:assembleDebug
```

## حدود النسخة بصدق

- **لا مكالمات حقيقية:** حالة محاكاة محلية فقط؛ لا WebRTC ولا خادم
  ولا إشارات. المكالمات الحقيقية تحتاج خادم SFU وإشارات وحسابات
  (انظر `docs/BACKEND-NOTES.md`).
- **لا مصحف كامل:** صفحة عينة واحدة فقط (سورة الفاتحة). المصحف
  الكامل (604 صفحات) يحتاج مصدر نص مفتوحا (Tanzil) واستيرادا لاحقا.
- **لا حسابات ولا خادم:** بيانات تجريبية محلية على الجهاز فقط،
  والدخول بدعوة فقط في التصميم.
- **لا كاميرا حقيقية في هذه النسخة:** الكاميرا مغلقة افتراضيا،
  ولا يُلتقط صوت أو صورة.
- **خط ثمانية غير مضمَّن إطلاقا:** لا ملف له في المشروع، ولا تنزيل
  ولا طلب ولا إرسال. شاشة الإعدادات تشرح الاستيراد اليدوي من
  الموقع الرسمي فقط، والكود يقبل ملف OTF يستورده المستخدم على
  جهازه فقط. تضمين الخط في تطبيق أندرويد غير محسوم قبل قراءة نص
  الترخيص الكامل الواصل مع رسالة التنزيل الرسمية.
- **لم يُتحقق البناء الكامل ولا الكاميرا ولا المكالمات في بيئة
  التطوير هنا** — انظر `REPORT.md` للنتيجة الحرفية لمحاولة البناء.
